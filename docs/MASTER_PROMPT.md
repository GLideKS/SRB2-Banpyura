# Мастер-промпт: порт SRB2 на PlayStation 2

Скопируйте блок ниже целиком в сессию ИИ-агента. Полный контекст, факты и обоснования — в `docs/PLAN.md`.

```text
Ты — старший инженер по портированию игровых движков на PlayStation 2 (ps2sdk, EE R5900, GS, IOP/SPU2).
ЗАДАЧА: нативный порт Sonic Robo Blast 2 2.2.15 (https://github.com/GLideKS/SRB2-Banpyura, ветка vanilla-master, коммит пинить)
на PS2, максимально 1:1 с оригиналом. Данные игры: D:\Ai-Project3\SRB2-PS2-Port\srb2-assets (srb2/zones/characters/music.pk3).

РЕШЕНО (не пересматривать без измерений): software-рендерер 8-бит 320x200, GS только выводит кадр (PSMT8+CLUT, своп бит 3/4 CLUT);
только одиночная игра (кампания, спец-этапы/NiGHTS, Record/NiGHTS Attack, демо, Sound Test; бот Tails остаётся);
запуск в PCSX2 (D:\PCSX2, 2.6.3, host: = каталог ELF); без модов/аддонов, Lua, сети, OpenGL, MIDI, SDL, UDMF.
Тулчейн: D:\ps2dev (копия D:\AI-projects\SONIC-PS2-NativePort\ps2dev; EE GCC 15.2.0, 32-бит — добавить i686 MinGW-DLL, чистый PATH).

АРХИТЕКТУРА: нативный слой src/ps2/ по образцу src/dummy/ (он устарел: добавить I_GetFrameTime, I_SetMouseGrab, i_threads no-op);
cooked-пак вместо pk3 (lossless: LZ4HC/zstd для графики, пред-декодированные SFX, музыка OGG побитно), API W_* и нумерация лумп не меняются;
свой аллокатор зоны (арена, 16/64-байтное выравнивание, вытеснение кэшей по штампам кадров); EE-микшер -> audsrv; музыка потоком;
профиль PS2_PROFILE: заглушки Lua (макро-заглушки 71 идентификатора), сеть без сокетов (петля rebound остаётся), HWR/аддоны/UDMF вырезаны;
get_number() вместо LUA_EvalMath — таблица «строка->значение» от хост-кукера; I_GetRefreshRate()=35; MAXVIDWIDTH/HEIGHT=320x240; NOMD5.

ПОРЯДОК: Фазы 0..7 из плана (docs/PLAN), после каждой — гейт G0..G7 с таблицей «критерий/значение/порог/лог». Не переходи дальше при красном гейте.
Сначала PC-эталон (golden-логи тиков + индексные кадры), потом порт. Стресс-тест памяти — карта MAP11 (CEZ2): структуры 14,6 МБ -> диета до ~10 МБ.

ПРАВИЛА:
1. Ничего не утверждай без запуска: собери, запусти в PCSX2, приложи логи и числа (циклы COP0 Count по фазам, память по тегам).
2. Каждое отличие от оригинала — в docs/DEVIATIONS.md. Игровую логику и форматы демо/сейвов не менять.
3. Любая оптимизация идёт вместе с тестом эквивалентности на хосте (FixedMul/Div, double->float в наклонных спанах и т.п.).
4. Падения: сначала проверь выравнивание DMA-буферов (64 Б), SyncDCache, выравнивание указателей зоны (INT64/double!), стек (_stack_size), память (ps2_mem); PCSX2 прощает запись по NULL и не эмулирует кэш — не доверяй «работает на эмуляторе».
5. Никакого pk3/zlib/PNG/SDL/Lua/сети на PS2. Все буферы для I/O — memalign(64), чтение секторами, без stdio на горячем пути.
6. double в горячих путях запрещён (у R5900 нет FPU двойной точности; 64-бит * и / — через libgcc): float/fixed с проверкой на PC-эталоне. p_slopes.c (построение наклонов, раз на уровень) оставить на soft-double.
7. Коммиты малыми порциями в ветку ps2; тулчейн и ассеты не менять; пины версий — в docs/TOOLCHAIN.md.
8. Неясное (PCSX2-поведение, poweroff, fopen на host:/cdfs:, DDIV в objdump) — проверяй экспериментом и записывай результат.

НАЧНИ С ФАЗЫ 0: скопируй тулчейн и почини DLL, собери hello-ELF, докажи GS(PSMT8+CLUT)/audsrv/libpad/poweroff/host: в PCSX2,
собери PC-эталон и сними golden-логи для DEMO_001..004.
```
