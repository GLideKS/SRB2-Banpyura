## Регрессионные тесты обнаруженных ошибок

* Зона: фактический PS2 allocator на x86 с 4-Б указателями и 32-Б header,
  **2414216 проверок**, 20000 alloc/free, 200 realloc. Учёт не дрейфует,
  alignbits до 16 даёт до 65536-Б выравнивание, lock не вытесняет кэши
  при исчерпании slack/симулированном malloc failure. Три негативных
  контроля воспроизводят старые ошибки; host-profile no-op тоже проверен.
* Blend: x86/x64, **31 таблица** при forward/reverse/shuffled/purge/LUT rebuild:
  0 различий в определённых байтах, девять TRANS совпадают полностью.
  Старая версия в reverse даёт **213841 различающийся байт**.
  Исходные 511 незаписанных edge bytes/таблица не объявляются эквивалентными.
* Текстуры: x86/x64, **четыре fixture × пять cases**; normalized snapshots
  совпадают с неизменённым host-layout. У BBFLRWAL **1739** pixel bytes;
  старый layout не проходит alignment, новый column/post массивы выровнены.
* Пак: **15052 записи**, **300940 partial reads**, CRC/names/order совпадают;
  **21** повреждённый вход отвергнут, два synthetic raw-block fixture проходят.
  Python SHA256 verifier также дал 0 расхождений. Source pk3/готовые паки
  не переписывались в этой сессии.

В архив также попал ранний неуспешный эксперимент `zone/ps2-x64/`:
он имитировал PS2 header на 64-битном MSVC (56 Б без нужного padding)
и не прошёл alignment. Это не EE ABI и не используемый теперь oracle.
Положительная проверка PS2-зоны — `zone/ps2-x86/` (32-Б header),
хостового профиля — `zone/host-profile/`. Файлы раннего эксперимента
сохранены как история, не засчитываются как PASS.
Нулевое число предупреждений в таблице относится к полной **EE** сборке;
у host CMake есть inherited deprecation/D9025, а blend-хост-тесты выводят
MSVC C4244 на исходных float/UINT16/UINT8 преобразованиях.
