# Бриф для рабочих агентов (Фаза 1, каркас платформы)

Проект: нативный порт Sonic Robo Blast 2 2.2.15 на PlayStation 2 (EE R5900, GS), запуск в PCSX2. Полный план — `docs/PLAN.md`
(читай разделы 4, 6, 7, 10, 11 по необходимости), реестр отличий — `docs/DEVIATIONS.md`, отчёт предыдущего гейта — `docs/GATES/G0.md`.
Рабочая копия: `D:\Ai-Project3\SRB2-PS2-Port`, ветка `ps2`. Ты работаешь в ОБЩЕМ рабочем дереве вместе с другими агентами.

## Текущий гейт (обновление 2026-10-01)
**G1 красный**: `docs/GATES/G1.md`, доказательства в `docs/GATES/g1/`.
Полная EE сборка 105 файлов без предупреждений; ELF 6986600 Б; title
35/70/105 совпадает с PC; idle 600 секунд завершён; хостовый профиль прошёл
4200 тиков/120 кадров/200 файлов четырёх демо с 0 отличий.
Остаются запрещённые PNG/zlib/ZIP/UDMF/remote/addon пути, временная
malloc-зона вместо D4 и hot soft-double. Не открывать G2 и не считать
временные леса разрешением менять требования.

## Железные правила
1. Ничего не утверждай без запуска. Собери, запусти, приложи числа/логи. Если проверить нельзя — так и напиши.
2. Игровую логику, форматы демо/сейвов НЕ менять. Любая правка ядра — только под `#ifdef PS2_PROFILE` (или `#ifdef PS2`), чтобы
   PC-сборка оставалась побайтно прежней. Каждое отличие от оригинала — строка в `docs/DEVIATIONS.md` (ID `PS2-nn`, следующий свободный;
   перед записью перечитай файл — его правят и другие; добавляй только свою строку).
3. Править можно ТОЛЬКО файлы из твоего списка владения (ниже в задании). Нужна правка чужого файла — не делай, опиши в отчёте.
4. НЕ делай `git commit`/`git add`/`git stash`/`git checkout`/`git reset`. Коммитит координатор.
5. Тулчейн `D:\ps2dev` и каталог `srb2-assets` не менять. Никакого pk3/zlib/PNG/SDL/Lua/сети в итоговом PS2-коде
   (zlib временно включён только как «леса» для чтения pk3 — это не твоя забота).
6. `double` в горячих путях запрещён. Все буферы под DMA/IO — `memalign(64)` + `SyncDCache`/`FlushCache`. Указатели на данные выровнены.
   PCSX2 прощает запись по NULL и не эмулирует кэш — «работает в эмуляторе» не доказательство.
7. Комментарии — как в окружающем коде (коротко, по делу). Код на C (gnu23). Без предупреждений: `-Wall -Wextra`.

## Инструменты
* Сборка движка: `python tools/ps2/build.py [--syntax] [--list-undefined] [файлы...]`. Список исходников — `tools/ps2/sources.txt`
  (несуществующие файлы пропускаются). Несколько агентов работают одновременно: ОБЯЗАТЕЛЬНО задай свой каталог вывода переменной
  окружения `SRB2_PS2_OUT` (например `D:\Ai-Project3\SRB2-PS2-Port\build\agent-<имя>`), иначе перетрёшь чужие объекты. Лог компиляции — `<out>\build.log`, линка — `<out>\link.log`.
  Общий каталог `build\ps2` — только у координатора.
  `--list-undefined` линкует с `--warn-unresolved-symbols` и позволяет перечислить, чего не хватает.
* Запуск в PCSX2: `python tools/ps2/run_pcsx2.py --elf <ELF> --log <лог> [--args=<аргументы>] [--timeout N] [--until "текст"] [--marker "P0 "]`.
  Обёртка держит общую блокировку — одновременно работает один эмулятор; ждать очереди нормально. `host:` = каталог ELF.
  Ничего другого для запуска PCSX2 не используй (не запускай `pcsx2-qt.exe` напрямую).
* Тулчейн вызывается только с чистым PATH (см. `tools/ps2/build.py`, `tools/ps2/build_hello.py`): иначе падает 0xC000007B.
  Для отдельных тестовых ELF можно скопировать приёмы из `tools/ps2/build_hello.py`/`hello.c` (там проверены GS PSMT8+CLUT с readback,
  audsrv, libpad, `host:`/`cdfs:` через stdio и fileXio, poweroff, загрузка IRX с `host:`).
* Хост-тесты на Windows: Python 3.12, MSVC (`cl`) через VS18 BuildTools при необходимости.
* PC-эталон: `golden/phase0-v2/run1/DEMO_00n/` (тики, кадры, `soc.tsv`, SFX). Не менять.

## Что уже есть
* `tools/ps2/build.py` собирает 104 файла (105 с `--ps2ref`) EE GCC 15.2.0 без CMake; ELF линкуется без неопределённых символов.
* `SRB2_CONFIG_PS2PROFILE=ON` в CMake даёт SDL-host профиль; сборка `tools/ps2/build_host_profile.ps1`,
  проверка `python tools/ps2/run_host_profile.py --output build/host-profile-g1/<новый-каталог>`.
* Пак-reader и его I/O пока FILE/stdio; `docs/PACK_FORMAT.md`. Готовые паки в `build/pak` не пересоздавать без задания.
* Регрессии зоны/blend/texture: `zone_hosttest.py`, `blend_hosttest.py`, `texture_hosttest.py` с `--negative-controls`.
* Образец устаревшего слоя — `src/dummy/*` и боевой `src/sdl/*` (логика); контракты — заголовки `src/i_system.h`, `i_video.h`, `i_sound.h`, `i_joy.h`.
* Макросы профиля, уже заданные сборкой: `PS2`, `PS2_PROFILE`, `NOHW`, `NOMD5`, `NO_PNG_LUMPS`, `NOMUMBLE`, `NO_IPV6`, `NOUPNP`, `HAVE_ZLIB`, `_EE`.

4. Записанные строки реестра отличий.
