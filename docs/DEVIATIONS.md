# Реестр отличий

Пин исходника: `0e09462308610005f640ed84b21ec8a4ef116a4b` (vanilla-master, SRB2 2.2.15).

Фаза 0: игровая логика, форматы демо и сейвов не изменены. Отдельный
`tools/ps2/hello.c` — диагностическая программа, а не порт движка.

| ID | Область | Отличие и проверка |
|---|---|---|
| REF-01 | Только PC, `SRB2_CONFIG_PS2REF=ON` | Опциональные наблюдательные хуки: каноническая сериализация состояния после тика, индексный кадр перед blit, копия декодированного SFX, результат настоящего `LUA_EvalMath`. Рендерер/математика/логика остаются исходными; штатное завершение `I_Quit` после демо. Повторяемость проверяется двумя полными прогонами. |
| REF-02 | Только PC/MSVC | `lzf.c`: `/Od /Ob0 /GL-` в reference-сборке. Исходная Release-сборка упала в CL с `-529706956`; после отключения оптимизации только этой единицы падение исчезло. Код LZF не изменён. Логи: `build/pc-golden/build.log`, `build-ref.log`, `build-ref2.log`. |
| REF-03 | Только PC/MSVC | VLA в экране загрузки сетевых аддонов заменён на `_alloca` того же размера. Причина: C2057/C2466/C2133, MSVC не реализует VLA. Ветвь других компиляторов сохранена; сетевая логика и исходные копирования структуры не изменены. Экран не используется в демо. |
| REF-04 | Только тестовый запуск `-ps2ref` | Контролируемые часы: `I_UpdateTime` продвигает платформенное время на один тик, `timefrac=0`; только при timescale=1. Исходный timedemo уже выполняет один игровой тик за кадр. Причина измерена: два полных прогона имели одинаковые тик-логи, но у DEMO_002 различались 2296 пикселей в полосе x=8..41 на тике 35. `G_PreLevelTitleCard` зависит от пропущенных тиков реального времени; штатная анимация титульной полосы потому неповторяема при загрузке. Не сбрасываем HUD и не меняем renderer; задаём воспроизводимый вход платформенных часов. Сравнение игровых логов с прогонами реальных часов — в отчёте G0. |

Данные `DEMO_001..004` не исправляются и не пересоздаются. Внутренние
демо старого формата могут выдавать штатные предупреждения движка о несовпадении
версии и desync. Это особенность исходника/данных эталона, не отличие PS2-порта;
подробности и пределы проверки фиксируются в `docs/GATES/G0.md`.
